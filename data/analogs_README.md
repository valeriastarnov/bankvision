# База аналогов `analogs.csv` — синтетическая

**Все записи вымышленные.** Производители, модели, годы, цены и даты «объявлений»
сгенерированы скриптом `data/generate_analogs.py` (seed 20261027). Данные не собраны
с рынка, не основаны на реальных объявлениях и **не отражают рыночные цены**.
Использовать их можно только для демонстрации работы алгоритма оценки.

Пересоздать (PowerShell):

```powershell
.\.venv\Scripts\python.exe data\generate_analogs.py
```

## Колонки

| Колонка | Смысл |
|---|---|
| `id` | Идентификатор записи (A001…) |
| `equipment_type` | Вид оборудования |
| `manufacturer` | Производитель (вымышленный) |
| `model` | Модель (вымышленная; для точных аналогов записана по-разному: «ТС-1640М», «TC-1640M», «ТС 1640М») |
| `year` | Год выпуска |
| `max_diameter_mm` | Наибольший диаметр обработки, мм (для токарных) |
| `center_distance_mm` | Расстояние между центрами, мм (для токарных) |
| `price_rub` | «Цена в объявлении», ₽ — сгенерирована, см. ниже |
| `listing_date` | «Дата объявления» — случайная дата 2025–2026 |
| `source` | Всегда `synthetic` |

## Как сгенерированы данные

- 34 записи в группах:
  - 6 — модель ТС-1640М (точные аналоги демонстрационного объекта);
  - 12 — токарно-винторезные того же класса (диаметр 380–420 мм, РМЦ 900–1100 мм), другие модели;
  - 8 — токарно-винторезные вне класса (диаметр 250, 500, 630 мм);
  - 8 — другое оборудование (токарный с ЧПУ, фрезерный, сверлильный).
- Для «ВЕКТОРСТАН-ДЕМО ЛТ-3200Ф» (станок токарный, 320/750 мм) намеренно нет ни
  точных, ни классовых аналогов — это сценарий «нет подходящих аналогов».
- Год выпуска — случайный, 2008–2024.
- Цена = условная «цена нового» модели × 0.93^(возраст на дату объявления) ×
  логнормальный шум (σ = 0.15), округление до 10 000 ₽. «Цена нового», коэффициент 0.93
  и шум выбраны произвольно.

## Что эти данные НЕ отражают

- реальные цены, спрос, ликвидность и сезонность рынка оборудования;
- реальное соотношение цен разных моделей и производителей;
- разницу между ценой предложения и ценой сделки;
- влияние состояния, наработки, комплектации и региона.

Обратите внимание: генератор использует похожий принцип снижения цены с возрастом,
что и алгоритм оценки. Поэтому на этой базе оценка выглядит «согласованной» — это
свойство синтетики, а не подтверждение точности метода.
