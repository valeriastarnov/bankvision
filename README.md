# BankVision

MVP интеллектуальной оценки залогового оборудования (хакатон «Финтех без границ»).
Все тестовые данные и база аналогов — **синтетические**. Система не принимает кредитного
решения и не решает, принимать ли залог.

> Черновик. Установка, запуск и проверка будут описаны в итерации 6.
> Сейчас README содержит только раздел «Ограничения», который пополняется по ходу работы.

## Ограничения

### Проверка качества фото (`app/services/image_quality.py`)

Проверено на отложенной синтетической выборке (`tests/RESULTS.md`, раздел
«Отложенная выборка»). Пороги не калиброваны на реальных фото.

- **Пересвет таблички на тёмном фоне не обнаруживается.** Метрика яркости — средняя
  по всему кадру; если табличка занимает часть кадра на тёмном фоне, её пересвет почти
  не меняет среднее (на выборке ×1.35 и ×1.6 дали 166.7 и 173.5 при пороге 200).
- **Флаги размытости и темноты срабатывают раньше, чем падает читаемость.** Гауссово
  размытие r = 1.5–3.0, смаз 9 px и затемнение до ×0.18 помечены флагами, хотя OCR
  на синтетике читал номер верно. Пользователь может получить лишнюю просьбу переснять.
- Запас резкости чётких фото над порогом небольшой (~160–190 при пороге 100).
- Совпадение значения с фото, у которого есть флаг качества, считается «совпадает»
  с пометкой, а не «не подтверждено» (решение по итерации 3).

### Распознавание и сверка

- OCR (Tesseract) читает кириллические модели вроде «ТС-1640М» латиницей; сверка
  нормализует двойники, но если и документ (скан), и фото распознаны одинаково неверно,
  сверка покажет «совпадает» — она сравнивает источники между собой, а не с истиной.
- Нормализация номера — только O/0 и I/l/1; путаницы S/5, B/8 не нормализуются.

### Оценка (`docs/methodology_valuation.md`)

- **Демонстрационная оценка на синтетических данных. Не является рыночной стоимостью.**
- База аналогов вымышленная (34 записи), цены сгенерированы произвольной формулой.
- Нет поправок на техническое состояние, наработку, комплектацию, регион, торг и дату
  объявления; цены предложения ≠ цены сделок.
- Коэффициент поправки на возраст (0.07 в год) — демонстрационное допущение.
